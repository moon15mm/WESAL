# دليل المستخدم — وِصال

**كل السوق في اتصال واحد.**

وِصال منصة تربط المحلات والسوبرماركت بالموردين والمندوبين. المورد يعرض منتجاته ويوصل الطلبات، والمحل يطلب ويدفع للمورد مباشرة، والمندوب يزور المحلات ويُعدّ الطلبات ضمن تفويض من الشركة. المنصة لا تستلم الأموال ولا تملك البضائع.

## البداية

1. افتح المنصة واختر اللغة من أيقونة الكرة الأرضية: العربية، الإنجليزية، الأردية، الهندية. يتغير اتجاه الصفحة تلقائياً.
2. اضغط **إنشاء حساب** واختر نوع الحساب: **محل تجاري**، **شركة / مورد**، أو **مندوب مبيعات**.
3. أدخل الاسم والجوال والبريد وكلمة مرور قوية، ثم وافق على الشروط.
4. أدخل رمز التحقق المرسل إلى بريدك وجوالك.
5. أكمل ملف منشأتك من **ملف المنشأة**، وارفع السجل التجاري ثم اضغط **إرسال للتوثيق**. يراجع فريق المنصة المستندات ويُشعرك بالنتيجة.

ننصح بتفعيل **التحقق الثنائي** من **الإعدادات ← الأمان** (إلزامي لحسابات إدارة المنصة)، واحفظ رموز الاسترداد في مكان آمن.

## المحل التجاري

| الشاشة | ماذا تفعل |
|---|---|
| **الرئيسية** | ملخص المشتريات، الطلبات التي تنتظر قرارك، أكثر الموردين تعاملاً، اقتراحات إعادة الطلب |
| **السوق** | ابحث بالاسم أو العلامة أو الباركود، قارن عروض الموردين لنفس المنتج، اختر الوحدة (حبة أو كرتون) والكمية ثم **إضافة** |
| **السلة** | سلة مستقلة لكل مورد؛ راجع الإجمالي والضريبة ورسوم التوصيل ثم **إرسال الطلب** |
| **الموافقات** | الطلبات التي أعدّها مندوب، وعروض الأسعار وتعديلات الموردين — لا يُعتمد شيء دون موافقتك |
| **الطلبات** | تتبع كل طلب: جديد ← معتمد ← قيد التجهيز ← في الطريق ← تم التسليم ← مكتمل |
| **إعادة الطلب الذكية** | اقتراحات مبنية على مشترياتك السابقة |
| **المرتجعات** | طلب إرجاع لأصناف تالفة أو ناقصة مع صور، ومتابعة قرار المورد |
| **الفروع** و**فريق العمل** | أضف فروعك، وادعُ موظفيك بأدوار مثل مدير فرع أو موظف مشتريات أو محاسب |

### الموافقة على طلب أعدّه مندوب

1. يصلك إشعار، ويظهر الطلب في **الموافقات** بحالة «بانتظار موافقة المحل».
2. افتح الطلب وراجع الأصناف والكميات والأسعار والعروض وموعد التوصيل.
3. اضغط **اعتماد** — يُحفظ ما وافقت عليه بالضبط، ولا يصل الطلب إلى المورد قبل ذلك.
4. أو اختر **طلب تعديل** أو **رفض** مع ذكر السبب.

إذا عدّل المورد السعر أو الكمية لاحقاً، يعود الطلب إليك لموافقة جديدة.

### الاستلام والدفع

عند وصول الشحنة افتح الطلب واضغط **تأكيد الاستلام**، وسجّل أي نقص أو تلف لكل صنف. الدفع يتم **للمورد مباشرة** بالطريقة المتفق عليها، ويسجل المورد إثبات التحصيل.

## المندوب

| الشاشة | ماذا تفعل |
|---|---|
| **الرئيسية** | زيارات اليوم، المبيعات المنسوبة إليك، العمولات المستحقة، المهام، حالة تفويضاتك |
| **الشركات** | اكتشف الشركات واطلب تفويضاً للعمل معها |
| **التفويضات** | راجع شروط كل تفويض (المنتجات، المدن، العمولة، المدة) ثم ضع علامة على «قرأت هذه الشروط واتفاقية العمولة وأوافق عليها» واضغط **قبول** |
| **الزيارات** | خطط زيارة أو ابدأها الآن؛ تسجيل الموقع يتم فقط بموافقتك عند بدء الزيارة وإنهائها |
| **العملاء** و**اكتشاف المحلات** | قاعدة عملائك ومحلات جديدة في مناطقك |
| **الكتالوج** | منتجات الشركات المفوَّض بها فقط، بأسعار المورد |
| **الطلبات ← طلب جديد** | اختر المحل والشركة، أضف الأصناف (أو استخدم **إدخال سريع** بكتابة الطلب كنص)، ثم **إرسال للمحل للموافقة** |
| **العمولات** | العمولة تمر بمراحل: متوقعة ← قيد الانتظار ← مستحقة ← معتمدة ← مدفوعة. يمكنك **الاعتراض** مع ذكر السبب |
| **ملفي المهني** | خبرتك ولغاتك ومناطقك وفئاتك، وظهورك في سوق المندوبين |

ملاحظات مهمة: لا يمكنك تعديل الأسعار، ولا إنشاء طلب خارج نطاق تفويضك، ولا يُعتبر الطلب نهائياً إلا بموافقة المحل.

## المورد / الشركة

| الشاشة | ماذا تفعل |
|---|---|
| **المنتجات** | أضف منتجاً (أو استورد ملف بيانات مفصولة بفواصل)، حدد سعر الحبة والكرتون والحد الأدنى والتوفر والمخزون والصورة |
| **الأسعار والعروض** | قوائم أسعار لعملاء أو مناطق محددة، وعروض بنسبة أو مبلغ أو حسب الكمية لفترة محددة |
| **مناطق التغطية** | المدن التي توصل إليها ورسوم التوصيل ومدة التوصيل |
| **الطلبات** | **قبول** الطلب، أو **تقديم عرض سعر** بأسعار أو كميات معدلة (يحتاج موافقة المحل)، ثم تجهيز ← جاهز ← إرسال مع السائق ← تم التسليم مع إثبات |
| **المندوبون** و**التفويضات** | راجع طلبات المندوبين، أصدر تفويضاً بالمنتجات والمدن واتفاقية العمولة والمدة، أوقفه أو ألغه مع ذكر السبب، وأضف مندوبي شركتك |
| **العمولات** | اتفاقيات العمولة وقواعدها، اعتماد العمولات المستحقة، تسجيل الدفع مع الإثبات، ومعالجة الاعتراضات |
| **العملاء** | ملف كل عميل ومصدر اكتسابه وتاريخ التعامل والملاحظات وجهات الاتصال |
| **المهام والأهداف** | مهام للمندوبين وأهداف بيعية |
| **المرتجعات** | قبول أو رفض طلبات الإرجاع وتسجيل الاستلام والتسوية |
| **التقارير** | المبيعات والمنتجات والمندوبين والعملاء، مع التصدير |

## التقارير والتصدير

كل تقرير يمكن تصديره كجدول أو ملف مفصول بفواصل أو ملف قابل للطباعة، بـ**لغة المستندات** التي تختارها من **الإعدادات** (قد تختلف عن **لغة الواجهة**)، مع اتجاه صحيح للعربية والأردية.

## المساعد الذكي

يمكنه تحويل نص مكتوب مثل «٥ كراتين مياه و٣ حليب» إلى أصناف مقترحة، والإجابة عن أسئلة مثل «كم مشترياتي هذا الشهر؟» من بياناتك فقط. لا يخترع أسعاراً ولا يعتمد طلبات ولا يغير أي بيانات.

## الإشعارات والخصوصية

* من **الإعدادات ← الإشعارات** اختر القنوات لكل نوع إشعار.
* من **الإعدادات ← الخصوصية** نزّل نسخة من بياناتك أو اطلب حذف حسابك.
* من **الإعدادات ← الجلسات النشطة** راجع الأجهزة المسجلة وأنهِ أي جلسة.

## الشكاوى والتقييم

بعد اكتمال الطلب يمكنك تقييم المورد والمندوب. ولأي مشكلة افتح **الشكاوى ← شكوى جديدة** واربطها بالطلب؛ يرد الطرف الآخر ويتابع فريق المنصة حتى الإغلاق.

## إدارة المنصة

**التوثيق** (مراجعة المنشآت والمندوبين)، **المستخدمون**، **الطلبات** و**العمولات** و**الشكاوى** للمتابعة، **الكتالوج** و**التقييمات** للإشراف، **الاشتراكات** و**الإعلانات**، **المحتوى** (الصفحات القانونية)، **اللغات والترجمة**، **الإعدادات**، **سجل التدقيق**، و**حالة النظام**.
